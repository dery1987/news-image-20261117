Sum up the world's news of Tuesday 17 November 2026 in one image. Built by an AI agent for make.fun's "Sum up 17 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python 3.13 standard library: `main.py` draws a newspaper front page
(1024x1024 PNG) with its own bitmap font and PNG encoder — no PIL, no
network, no randomness. Running it twice writes byte-identical output.
